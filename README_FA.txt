ARIS Mobile — نسخه آزمایشی 1.0

این بسته یک وب‌اپ رایگان و مستقل است. قابلیت‌ها: وظایف، یادداشت‌ها، پشتیبان JSON و گفت‌وگوی نمایشی.
هوش مصنوعی واقعی، اتصال به لپ‌تاپ، پیامک، تماس و کنترل حساب‌ها هنوز پیاده‌سازی نشده‌اند.

برای آزمایش روی آیفون:
۱. پوشه را روی یک سرویس میزبانی فایل استاتیک HTTPS قرار دهید (مثلاً GitHub Pages با مخزن خصوصی/عمومی متناسب با نیازتان). انتشار روی یک هاست به معنی عمومی شدن فایل‌های کد است؛ اطلاعات شخصی را داخل کد قرار ندهید.
۲. آدرس HTTPS صفحه index.html را در Safari آیفون باز کنید.
۳. Share > Add to Home Screen > Open as Web App > Add.
۴. از بخش وظایف و یادداشت‌ها آزمایش کنید.

نکته: بازکردن مستقیم فایل index.html از Files برای نصب PWA و Service Worker کافی نیست. برای نصب واقعی به URL با HTTPS نیاز است.
داده‌های وظایف/یادداشت‌ها در localStorage همان مرورگر ذخیره می‌شود و رمزگذاری اختصاصی ندارد.
این نسخه هیچ API پولی یا کلید دسترسی لازم ندارد.
